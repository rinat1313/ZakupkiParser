# ZakupkiParser

Исследование и заготовка парсера госзакупок (тендеров) с сайта [ЕИС zakupki.gov.ru](https://zakupki.gov.ru) по **44-ФЗ** и **223-ФЗ**.

Цель проекта: научиться автоматически **искать закупки**, **читать карточку по номеру**, **скачивать документы**, складывать данные в структуру/СУБД и дальше передавать на анализ (скоринг, риски, сравнение НМЦК и т.д.).

> Статус: этап анализа HTML/API и каркас на Go. Рабочий end-to-end парсер ещё в разработке.

## Зачем

Публичного удобного REST API ЕИС «для всех» без ЭЦП нет. Практичный путь для pet/MVP:

1. HTML/XML публичных страниц (SSR)
2. при возможности — printForm XML по `regNumber`
3. позже — getDocsIP (токен) или SOAP (КЭП юрлица)

Подробности: [`result/01_api_i_oficialnye_kanaly.txt`](result/01_api_i_oficialnye_kanaly.txt).


## DataCode (Go)

```
DataCode/
  models/           # структуры Notice44, Notice223, Organization, Document…

  docs/             # как работать со структурами
  internal/parser/  # парсеры fz44 (и позже fz223)
  pkg/eis/          # HTTP-клиент
  cmd/parser/       # CLI
  data/tenders.csv  # входной список номеров извещений
  AI_AGENT.txt      # краткий контекст для AI при разработке
  scripts/eis_curl/ # smoke-тесты curl к живому сайту
```

### Запуск парсера

```bash
cd DataCode
go run ./cmd/parser -limit 1
go run ./cmd/parser -csv data/tenders.csv -o data/out.json
```

### Проверка доступа к ЕИС

```bash
bash DataCode/scripts/eis_curl/run_all.sh
# или один запрос:
bash DataCode/scripts/eis_curl/02_notice44.sh
```

Ответы сохраняются в `DataCode/scripts/eis_curl/out/`.

На части macOS у `curl` бывает ошибка SSL (`unable to get local issuer certificate`) — в скриптах уже используется `-k` для локальных тестов.

## Типовой поток данных

```
поиск / номер → карточка извещения → документы (filestore) → организация
             → (опционально) журнал / итоги / лоты 223 → СУБД → анализ
```

Пример URL (44-ФЗ):

```text
/epz/order/notice/ea20/view/common-info.html?regNumber=…
/epz/order/notice/ea20/view/documents.html?regNumber=…
/44fz/filestore/public/1.0/download/priz/file.html?uid=…
```

Пример URL (223-ФЗ):

```text
/epz/order/notice/notice223/common-info.html?noticeGuid=…&regNumber=…
/223/filestore/public/1.0/download/fz223/file.html?uid=…
```

## Ограничения и риски

- Rate limit ЕИС (ориентир: не больше ~3 параллельных запросов, retry на 429/пустой ответ)
- Вёрстка сайта периодически меняется — нужны смоук-тесты на фикстурах из `html/`
- Идентификаторы заказчика: ИНН / organizationCode / organizationId / agencyId — разные, нужен mapping
- Массовый парсинг публичного сайта — соблюдать разумную нагрузку и правила использования

## Лицензия и данные

HTML в `html/` — сохранённые публичные страницы ЕИС для разработки парсера.  
Материалы в `over/` — сторонние статьи/заметки; права на них принадлежат авторам оригиналов.

Проект учебный / pet; не является официальным ПО Минфина или ЕИС.
