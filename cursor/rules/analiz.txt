- В папке html хранятся типовые сайты страниц откуда надо будет брать информацию.
- В папке html есть две папки 44 фз и 223 фз.
- В папке 44 фз хранятся html страницы которые связаны с закупками по 44 федерацльному закону.
- В папке 223 фз хранятся html страницы которые связаны с закупками по 223 федеральному закону.
- В папке over хранится информация других пользователей кто уже пробовал парсить html файлы с нужной нам информацией (опыт других разработчиков).
- Вносить изменения в файлы папок html, over нельзя.
- В папке result хранится информация по ранее проведённому анализу. На основании этих данных повторный анализ проводить не надо.
- Строго не проводим парсинг файлов которые уже парсились для анализа данных которые указаны в папке result.
- Весь код проекта (Go, CLI, tenders.csv, скрипты парсера) писать только в папке DataCode.
