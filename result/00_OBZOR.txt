РУКОВОДСТВО ПО ПАРСИНГУ ЕИС (zakupki.gov.ru)
================================================
Источник анализа: папки html/ и over/ проекта «анализ госзакупки».
Дата подготовки: 2026-08-02.
Пример закупки в образцах HTML: № 0134300097526000797 (44-ФЗ, электронный аукцион).


ЧТО НУЖНО СДЕЛАТЬ В ПРОДУКТЕ (ЦЕЛЬ)
-----------------------------------
1. Искать закупки/тендеры (ключевые слова, фильтры, номер).
2. Открывать карточку по номеру извещения (regNumber).
3. Читать поля: объект, заказчик, НМЦК, даты, статус, ИКЗ и т.д.
4. Скачивать вложения (обоснование НМЦК, проект контракта и др.).
5. Сохранять всё в СУБД.


КРАТКИЙ ОТВЕТ: ПАРСИНГ ИЛИ REST API?
-----------------------------------
Публичного «удобного REST API ЕИС для всех» без регистрации/ЭЦП НЕТ.

Варианты:
A) HTML/XML публичных страниц (без ЭЦП) — основной рабочий путь.
B) printForm XML по regNumber — полуструктурированный XML без парсинга вёрстки.
C) getDocsIP (токен сервисов отдачи ЕИС) — массовая выгрузка XML, если есть токен.
D) SOAP int44.zakupki.gov.ru — официально, но нужна КЭП юрлица.
E) FTP с XML — ЗАКРЫТ с 01.01.2025.
F) opendata.gov.ru — каталог без рабочих ссылок на скачивание.
G) Сторонний REST (gosplan и аналоги) — посредник, не первоисточник.

Рекомендация для старта без ЭЦП юрлица:
  поиск HTML → карточка HTML/printForm XML → документы filestore → БД.
  Подробности: 01_api_i_oficialnye_kanaly.txt

ПОТОК ДАННЫХ (МИНИМУМ)
----------------------
1. GET /epz/order/extendedsearch/results.html?searchString=...&fz44=on
2. Из карточки списка взять href на common-info.html?regNumber=...
3. Парсить common-info (или printForm/viewXml.html?regNumber=...)
4. documents.html?regNumber=... → ссылки filestore?uid=...
5. Скачать файлы, сохранить метаданные + blob в БД
6. (опционально) event-journal.html, затем поиск контракта по orderNumber
