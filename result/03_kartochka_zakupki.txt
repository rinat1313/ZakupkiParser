03. КАРТОЧКА ЗАКУПКИ (ИЗВЕЩЕНИЕ)
================================
Образец: html/Сведения закупки.html
Пример: regNumber=0134300097526000797
Тип в образце: ea20 (электронный аукцион 44-ФЗ)


1. URL ВКЛАДОК
-------------
Общая информация:
  /epz/order/notice/ea20/view/common-info.html?regNumber=0134300097526000797

Документы:
  /epz/order/notice/ea20/view/documents.html?regNumber=...

Журнал событий:
  /epz/order/notice/ea20/view/event-journal.html?regNumber=...

contextPath в JS: "/epz/order/notice"
Навигация вкладок: .tabsNav__item[href]


2. АЛЬТЕРНАТИВА HTML — PRINTFORM XML
-----------------------------------
https://zakupki.gov.ru/epz/order/notice/printForm/viewXml.html?regNumber=0134300097526000797

Рекомендуемый порядок обогащения:
  1) viewXml по regNumber
  2) добор полей из HTML common-info
  3) документы — HTML documents


3. ШАПКА КАРТОЧКИ (.cardMainInfo)
--------------------------------
Селекторы:
  .cardMainInfo__title          — закон / способ
  .cardMainInfo__purchaseLink a — № извещения
  .cardMainInfo__state          — этап («Подача заявок»)
  .cardMainInfo__content        — объект закупки, организация
  .cardMainInfo__content.cost   — цена

Пример из образца:
  Закон/способ: 44-ФЗ, Электронный аукцион
  Номер: 0134300097526000797
  Статус: Подача заявок
  Объект: Приобретение жилого помещения (квартиры) путем участия
          в долевом строительстве ... (программа переселения, Иркутск)
  Организация размещения: organizationCode=01343000975
    КОМИТЕТ ПО ЭКОНОМИКЕ И СТРАТЕГИЧЕСКОМУ ПЛАНИРОВАНИЮ АДМИНИСТРАЦИИ Г. ИРКУТСКА
  Цена: 7 758 776,51 ₽
  Даты: Размещено 01.08.2026, Обновлено 01.08.2026,
        Окончание подачи заявок 11.08.2026


4. ДЕТАЛЬНЫЕ БЛОКИ (.blockInfo)
------------------------------
Паттерн полей (парсить по подписи, не по порядковому номеру):
  .blockInfo
    h2.blockInfo__title
    section.blockInfo__section
      span.section__title  ← русская подпись
      span.section__info   ← значение

Ключевые блоки и поля (из образца):

A) Общая информация о закупке
  - Способ определения поставщика: Электронный аукцион
  - ЭТП: РТС-тендер (http://www.rts-tender.ru)
  - Размещение осуществляет: Уполномоченный орган + org
  - Наименование объекта закупки
  - Этап закупки
  - Позиция плана-графика: 202601343000974001000245
    ссылка: /epz/orderplan/pg2020/position/general-info.html?plan-number=...&position-number=...

B) Контактная информация
  - Организация, адрес, место нахождения
  - Ответственное лицо (пример: Одинец В. Н.)
  - Email, телефон
  - Регион (Иркутская обл)
  - «Дополнительная информация» — часто там реальный заказчик

C) Информация о процедуре
  - Начало / окончание подачи заявок (с таймзоной МСК±N)
  - Дата подачи ценовых предложений
  - Дата подведения итогов
  - span.timeZoneName (title с городом)

D) Начальная (максимальная) цена контракта — НМЦК
  - Подпись: «Начальная (максимальная) цена контракта»
  - Значение в образце: 7 758 776,51
  - Валюта: РОССИЙСКИЙ РУБЛЬ
  - ИКЗ: 263380819349338080100102490014120412

E) Объект закупки (таблица)
  - #positionKTRU, #purchaseObjectTruTable1
  - table.blockInfo__table.tableBlock
  - Колонки: код позиции, наименование ТРУ, ед., кол-во, цена, стоимость
  - Пример: ОКПД2 41.20.10.110, «Жилое помещение (квартира)», 1 шт
  - Скрытые строки характеристик: .truInfo_* {display:none}

F) Обеспечение заявки / исполнения
  - Размер обеспечения заявки (пример: 38 793,88)
  - ИНН/КПП получателя (в образце: 3808193493 / 380801001)
  - КБК, ОКТМО, казначейские счета

G) Сроки и финансирование
  - Срок исполнения (пример: 30.12.2027)
  - Бюджет (местный / городской и т.д.)

Часть финансовых таблиц может подгружаться AJAX:
  /epz/order/notice/ea20/view/common-info-tab/fin-source-info/budget-table.html?regNumber=...

6. ЗАКАЗЧИК: ТРИ ФОРМАТА ID (ИЗ over/info.txt)
---------------------------------------------
Один юр. субъект в ЕИС может фигурировать как:
  ИНН              — 10 или 12 цифр (настоящий)
  organizationId   — 5–8 цифр (внутренний)
  organizationCode — 11 цифр (часто в URL ленты)

Без таблицы алиасов джойны «ломаются».
Нужен mapping: любой вход → канонический ИНН.
См. 07_arkhitektura_praktika.txt.


7. НМЦК — ГДЕ БРАТЬ И КАК НЕ ОШИБИТЬСЯ
-------------------------------------
- НМЦК на странице ИЗВЕЩЕНИЯ (common-info), не на карточке контракта.
- Парсить ТОЛЬКО каноническую подпись
  «Начальная (максимальная) цена контракта».
- Не подменять синонимом «Максимальное значение цены договора»
  (у рамочных договоров это лимит на годы → ложный дисконт ~99%).
- Если точного числа нет (диапазон «не более …») — писать NULL.
- По опыту over/: точное число НМЦК есть далеко не у всех извещений.


8. 44-ФЗ VS 223-ФЗ
------------------
Разные URL, классы, параметры заказчика (organizationId vs agencyId),
разный поиск контрактов. Два независимых парсера за общим интерфейсом.
