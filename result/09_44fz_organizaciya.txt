2. ВАЖНО ПРО ДВА HTML-ФАЙЛА
---------------------------
«Учётная карточка» и «Дополнительная информация» — одна страница с разными
активными вкладками. Оба блока (#tab-info и #tab-other) часто есть в DOM;
неактивный скрыт классом d-none.

Парсер: читать ОБА панели из одного ответа, не ждать двух загрузок.


3. ШАПКА
--------
.search-registry-entry-block / .registry-entry__*
  номер/название, ОГРН, ИНН, КПП, местонахождение, badge «44-ФЗ»


4. ВКЛАДКА tab=info — УЧЁТНАЯ КАРТОЧКА (#tab-info)
-------------------------------------------------
Паттерн полей: h2.blockInfo__title → section.blockInfo__section
  → span.section__title + span.section__info

Блоки и поля (пример organizationCode=01622000077):
  ИКО в ЕИС (таблица; может грузиться AJAX iko-list.html?organizationId=)
    ИКО, полномочие «Заказчик», дата
  Регистрационные данные
    Полное / сокращённое наименование
    Код по Сводному реестру (НЕ путать с organizationCode)
    Дата регистрации, дата/время последнего изменения
    ИНН, КПП, ОГРН, ОКТМО, место нахождения
  ИКУ — код и дата присвоения
  Форма собственности (код ОКФС + наименование)
  ОКОПФ (код + наименование)


5. ВКЛАДКА tab=other — ДОП. ИНФОРМАЦИЯ (#tab-other)
---------------------------------------------------
  Полномочия организации, Уникальный учетный номер (= organizationCode)
  Дата постановки на учет, тип, уровень
  Коды: ОКПО, ОКВЭД
  Бюджеты
  Административная принадлежность (ИНН/КПП РОДИТЕЛЯ ≠ ИНН организации)
  Уполномоченная организация / органы (могут быть пустыми / AJAX #innerUos)


6. КОНТАКТЫ (ВНЕ ВКЛАДОК — всегда видны)
----------------------------------------
Телефон, факс, почтовый адрес, email, контактное лицо, часовая зона.

9. ЛОВУШКИ
----------
- Подпись «Наименование» повторяется в разных блоках — брать в контексте h2.
- organizationCode (11 цифр) ≠ код Сводного реестра.
- ИНН ведомства-родителя ≠ ИНН самой организации.
- Не парсить только активную вкладку — снять d-none с обеих.
